# KGP Notice Bot

A personal, single-user tool that watches the IIT Kharagpur ERP Training & Placement portal for
new CDC notices and company openings, and sends push notifications to its owner.

To log in to ERP, it reads the one-time password (OTP) that ERP emails to the owner's own Gmail
inbox. Gmail access is read-only and used only for that purpose - see the [privacy policy](PRIVACY.md).

This app is not offered to anyone else and is not affiliated with IIT Kharagpur or Google.
